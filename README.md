# PSG Plumbing

Website for Piers Stuart Gray — plumbing, heating and gas across Cumbria.

## Local

```bash
npm install
npm run dev
```

Open http://127.0.0.1:8080/

## Railway env

- `BUSINESS_PHONE` — show phone on site
- `BUSINESS_EMAIL` — optional
- `WEB3FORMS_ACCESS_KEY` — email lead notifications (optional)

Contact leads are stored in `data/leads.json` on the server.
